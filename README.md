# 📊 ECG Clinical Data Analysis and Visualization

This repository contains Python scripts developed to support the analyses presented in the associated research article "BRAZILIAN TELEDIAGNOSTIC ECG DATASET WITH CLINICAL REPORTS FOR CHRONIC RESPIRATORY DISEASES". The codebase focuses on preprocessing, validation, and visualization of structured clinical data and ECG signals.

---

## 🔗 Data Availability

The dataset used in this study is publicly available on Zenodo:

👉 [Access dataset on Zenodo](https://zenodo.org/record/XXXXX)

> Replace `XXXXX` with your actual Zenodo record ID.

## Overview

The repository provides tools for:

- Data validation and quality assessment  
- Missing values analysis  
- Duplicate patient detection  
- Geographic and demographic distribution analysis  
- ECG signal visualization from JSON files  
- Generation of publication-ready outputs  

All scripts are standardized in English to support reproducibility and international research use.

---

## Research Context

The scripts support the analysis of clinical datasets related to ECG exams, including patient demographics and exam distribution.

They are designed to:
- Ensure **data integrity and consistency**
- Enable **exploratory data analysis (EDA)**
- Support **scientific publication workflows**
